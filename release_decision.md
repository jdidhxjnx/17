# Решение по выпуску 1.5.0-rc1 (DOC-17)

## Решение: ОСТАНОВИТЬ выпуск (не продолжать в окне 18:00–18:30).

## Основание
1. **R_RESTORE — blocked:** нет среды восстановления, RTO/RPO не подтверждены; критический сценарий восстановления не проверен.
2. **R_PERFORMANCE — not_run:** измерение не проводилось; пустой/заблокированный тест не считается успешным.
3. **Контроль целостности пакета** не подтверждён (хеш не вычислен).
4. **Документация противоречива** (лимит вложений, совет при тайм-ауте).
5. Пороги качества не снижаются ради принятия непроверенного кандидата.

## Минимальные действия для пересмотра
| Действие | Владелец | Требуемое доказательство |
|---|---|---|
| Испытание восстановления RTO ≤20 мин, RPO ≤15 мин | teacher_release + student_engineer | отчёт с фактическими временами и контрольным набором |
| Измерение производительности ≥99%, p95 ≤800 мс | student_tester | журнал нагрузки и расчёт p95 |
| Вычислить хеш пакета | student_engineer | вычисленный хеш |
| Внести исправления руководства в пакет | student_engineer | обновлённый guide 1.5.0 |
| Проверить совместимость при category_required | student_tester | результаты проверки S1/S2 |

## Условие следующего рассмотрения

Решение может быть пересмотрено **только при одновременном выполнении всех условий**:

1. Все 5 действий из таблицы выше выполнены.
2. По каждому действию приложено требуемое доказательство (отчёт восстановления с фактическими временами; журнал нагрузки и расчёт p95; вычисленный хеш; обновлённый guide 1.5.0; результаты проверки S1/S2 при category_required).
3. Ни один подтверждённый дефект доступа, потери данных или дубля не остаётся открытым.

Ответственный за пересмотр — `teacher_release`; приёмка — `teacher_process`. До выполнения условий статус остаётся «ОСТАНОВИТЬ».
